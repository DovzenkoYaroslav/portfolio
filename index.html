Задача и контекст

В ООО «ФИТ-ПРОСТРАНСТВО» процесс подачи заявок был хаотичным (Email, мессенджеры). Это приводило к потере данных и трате 40% рабочего времени менеджеров на рутину.

Цель: Создать единый цифровой канал через Mobile API.

Технологический стек
REACT NATIVE EXPO NODE.JS EXPRESS MONGODB ATLAS REST API

Использование сквозного JavaScript (Fullstack JS) обеспечило высокую скорость обмена данными в формате JSON.

Функционал
  • • Динамические формы с условным рендерингом.
  • • Авторизация и восстановление доступа.
  • • Автоматический почтовый шлюз Nodemailer.
Результат

Процесс обработки ускорен на 40%. Исключены ошибки ручного ввода и создана прозрачная история заявок для B2B-партнеров.

Задача и контекст

Разработка десктопного приложения для ООО «Обувь» в рамках стандартов WorldSkills. Требовалось создать систему с ролевой моделью и полным циклом управления товарами.

Цель: Создать стабильную, масштабируемую ИС, готовую к реальной эксплуатации.

Технологический стек
C# .NET WINFORMS MSSQL ADO.NET GDI+

Трехуровневая архитектура (PL, BLL, DAL) с паттернами Singleton и Repository.

Особенности реализации
  • • Кастомный UI: скругленные углы, тени, анимации через GDI+.
  • • Цветовая индикация товаров со скидкой >15%.
  • • Динамическая подгрузка изображений для производительности.
  • • Защита от SQL-инъекций и валидация ввода.
Результат

Система полностью соответствует стандартам WorldSkills. Демонстрирует владение C#, MS SQL, ADO.NET и принципами ООП в контексте настольных бизнес-приложений.
