Задача и контекст

В ООО «ФИТ-ПРОСТРАНСТВО» процесс подачи заявок был хаотичным (Email, мессенджеры). Это приводило к потере данных и трате 40% рабочего времени менеджеров на рутину.

Цель: Создать единый цифровой канал через Mobile API.

Технологический стек
REACT NATIVE EXPO NODE.JS EXPRESS MONGODB ATLAS REST API

Использование сквозного JavaScript (Fullstack JS) обеспечило высокую скорость обмена данными в формате JSON.

Функционал
  • • Динамические формы с условным рендерингом.
  • • Авторизация и восстановление доступа.
  • • Автоматический почтовый шлюз Nodemailer.
Результат

Процесс обработки ускорен на 40%. Исключены ошибки ручного ввода и создана прозрачная история заявок для B2B-партнеров.

Технический отчет

Задача и контекст

Разработка полнофункциональной веб-игры для игры в Техасский Холдем и Блэкджек с друзьями в реальном времени. Требовалось создать многопользовательскую систему с комнатами, ботами и персистентностью статистики.

Цель: Создать стабильную real-time платформу для casual-игры с друзьями.

Технологический стек
NODE.JS EXPRESS SOCKET.IO VANILLA JS JSON

Real-time коммуникация через Socket.IO. Персистентность через JSON-файлы с атомарной записью.

Техасский Холдем
  • • До 10 игроков, до 100 комнат.
  • • Полный цикл раздачи: префлоп, флоп, тёрн, ривер, шоудаун.
  • • Оценка рук через C(7,5) = 21 комбинация.
  • • Корректные сайд-поты и распределение банка.
  • • Боты со случайными действиями.
  • • Таймаут хода 30 секунд.
Блэкджек
  • • Соло-режим на клиенте (localStorage).
  • • Онлайн-режим до 7 игроков.
  • • 6-колодный шуз (312 карт).
  • • Дилер тянет до 17 (S17).
  • • Выплаты: 1:1, Blackjack 3:2.
  • • Таймаут хода 20 секунд.
Особенности реализации
  • • Монолитная архитектура: бэкенд ~1330 строк, фронтенд ~1850 строк.
  • • Vanilla JS без фреймворков, тёмная тема с золотыми акцентами.
  • • Атомарная запись JSON через temp + rename.
  • • Валидация всех сокет-входов, очистка устаревших комнат.
Результат

Полностью функциональное веб-приложение для игры в покер и блэкджек с real-time мультиплеером. Корректно реализованы сложные механики: сайд-поты, C(7,5) оценка рук, ace-low стрит и многоуровневые выплаты в блэкджеке.
